# Contribuir com o DeepFind

Projeto GPL-3.0-only. Faça PRs pequenos com testes. Toda nova fonte de arquivos deve preservar o princípio somente leitura e permissões explícitas. Toda assinatura deve descrever evidências e limitações, sem identificar contêiner como conteúdo validado. Nunca enviar dados de dispositivos reais em issues; usar fixtures sintéticas. CI deve passar antes do merge.
