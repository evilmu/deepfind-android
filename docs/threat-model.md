# Modelo de ameaças

Fonte externa é não confiável: nomes, MIME, tamanho, diretórios e bytes do provedor. Não executar conteúdo. Não criar arquivos durante leitura. Limitar entradas/profundidade/cabeçalho e oferecer cancelamento. Relatórios podem conter informações pessoais e só são exportados com interação do usuário. Sem permissão INTERNET na versão alpha. Root futuro separado e opt-in. Não reivindicar certeza forense apenas a partir de assinatura binária.
