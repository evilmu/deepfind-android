# Segurança

Não publique credenciais, dumps, arquivos pessoais ou dados sensíveis em issues públicas. Para reportar vulnerabilidades, use GitHub Security > Report a vulnerability quando o recurso estiver habilitado, ou contate os mantenedores por canal privado. O DeepFind é uma ferramenta de triagem experimental; não garante integridade forense certificada. Não há coleta de telemetria no alpha.
